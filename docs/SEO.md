# SEO: семантическое ядро и индексация

Сайт: https://kafka.kz. Метаданные страниц (title, description, keywords, schema.org) — `src/lib/seo.ts`. Этот файл — полный список запросов, под которые продвигается сайт, и порядок индексации.

## Как пользоваться ядром

- В `<meta name="keywords">` каждой страницы стоят основные запросы её кластера. Google этот тег не учитывает, Яндекс почти не учитывает — **ранжирует текст страницы**: H1, H2, первые абзацы, FAQ, подписи. Новый важный запрос должен появиться в видимом тексте страницы (`design/project/*.dc.html`), а не только в `seo.ts`.
- Один кластер = одна страница. Не размазывать «интеграцию iiko» по пяти страницам — это создаёт конкуренцию страниц сайта между собой.
- Кластеры с пометкой **нет страницы** — кандидаты на новые SEO-лендинги по образцу `/integrations/rkeeper`.
- Частотность проверять в Яндекс Wordstat (регион «Казахстан») и Google Keyword Planner перед тем, как писать лендинг.

## Индексация

Техническая часть уже сделана: `sitemap.xml`, `robots.txt` (с `Clean-param` для UTM в Яндексе), canonical, 301 с `/x/` и `/x/index.html` на `/x`, http и www → https://kafka.kz (это делает Plesk), schema.org, 404 с `noindex`.

### Один раз

1. **Яндекс Вебмастер** (webmaster.yandex.ru) → добавить `https://kafka.kz` → способ «Мета-тег» → скопировать значение `content` в `yandexVerification` в `src/lib/seo.ts` → `npm run deploy` → нажать «Проверить». Затем: «Индексирование → Файлы Sitemap» → `https://kafka.kz/sitemap.xml`; «Индексирование → Переобход страниц» → отправить все 6 адресов; «Информация о сайте → Региональность» → Казахстан, Алматы.
2. **Google Search Console** (search.google.com/search-console) → ресурс «Префикс URL» `https://kafka.kz` → «Тег HTML» → значение в `googleVerification` → деплой → «Подтвердить». Затем «Файлы Sitemap» → `sitemap.xml`; «Проверка URL» → «Запросить индексирование» для главной и `/integrations/rkeeper`.
3. **Яндекс Метрика** — номер счётчика в `yandexMetrikaId` (счётчик подключается сам). Привязать счётчик к сайту в Вебмастере.
4. **Bing Webmaster Tools** — «Import from Google Search Console» (даёт ещё и поиск в ChatGPT/Copilot).
5. **Карточки компании**: Яндекс Бизнес, Google Business Profile, 2ГИС — адрес и телефон те же, что в футере и `SITE`.
6. **Внешние ссылки**: каталоги SaaS/HoReCa Казахстана, партнёры (дилеры r_keeper/iiko), профили в соцсетях.

### После каждого деплоя

```
npm run deploy        # сборка dist/ → коммит → push → Plesk забирает
npm run indexnow      # когда Plesk обновил сайт: отправить URL в Яндекс и Bing
```

`npm run indexnow` (`scripts/indexnow.mjs`) отправляет все адреса из `dist/sitemap.xml` по протоколу IndexNow. Ключ — файл `public/<ключ>.txt`, он должен быть доступен на сайте (скрипт проверяет это сам). Можно передать отдельные адреса: `node scripts/indexnow.mjs https://kafka.kz/pricing`. Google IndexNow не поддерживает — для него хватает sitemap и Search Console.
