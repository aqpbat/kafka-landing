# План реализации сайта Kafka

Цель: превратить утверждённый макет (канвас «Kafka — лендинг», копия в `design/project/`) в настоящий быстрый сайт, запустить локально и дальше точечно править по демонстрации.

## Подход

Сайт **собирается прямо из файлов макета** (`design/project/*.dc.html`), а не переписывается вручную:

- Разметка и стили артбордов переносятся один в один → пиксель-в-пиксель с макетом.
- Логика артбордов (`class Component extends DCLogic`: слайдеры, карусели, конструктор, FAQ) исполняется в браузере через небольшой рантайм (`src/lib/dc/`).
- Правка макета = правка сайта. Изменения можно публиковать обратно в канвас, и дизайн с кодом не разъезжаются.

Стек: **Astro 7** (статическая сборка), шрифты локально через `@fontsource` (Montserrat 400–900, Fraunces 800), без UI-фреймворка. Главная содержит две вёрстки: десктопный артборд показывается от 761 px, мобильный — до 760 px. Внутренние страницы адаптивные по правилам самого макета.
